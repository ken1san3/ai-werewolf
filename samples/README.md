# 代表試合のリプレイ

ローカルLLMの9体のAIが実際に対戦したゲームのうち、代表的な4試合を収録しています。
LLMやゲーム記録の原本がなくても、このリポジトリだけでリプレイを再生できます。

## 見る

`html/index.html` をブラウザで開くと試合一覧が表示され、行を選ぶと再生画面に移ります。
各試合のHTMLは1ファイルで完結しているので、ダウンロードしてそのまま開けます。

## 作り直す

リプレイのHTMLは、このフォルダの公開データから毎回同じ内容で作り直せます（LLMは使いません）。

```bash
python -m ai_agent.replay --root samples --output samples/html
```

`tests/test_replay.py` で、作り直したHTMLが収録済みのHTMLと一致することを確認しています。

## 収録していない情報

各試合のデータは `python -m ai_agent.replay_export <記録フォルダ> <書き出し先>` で、元の記録から書き出しました。
書き出しには、リプレイの画面と同じ許可リストを使っています。収録しているのは次の情報だけです。

- フェーズの開始、公開チャット、正式なCO、投票の集計、死亡と公開された死因、勝敗
- ゲーム終了時に公開される全員の役職と勝敗
- 時間設定・試合時間・開始時刻

人狼や妖狐の秘密チャット、占い・霊能などの非公開の結果、夜の能力の対象、各自の投票先、
AIの発言前の判断記録（`decisions.json`）、品質チェックの詳細（`checks.json` の大部分）は含めていません。
