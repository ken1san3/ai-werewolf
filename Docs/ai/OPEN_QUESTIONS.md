## Q2 [Phase 1 前に必須] 村の勝利条件の定義

マスター仕様 §10 は村の勝利条件を `eliminate_team: target: wolf` としている。
しかし狂人が `team: wolf` の場合、**狂人が生存している限り村が勝てない**。

選択肢:

- A: 勝利条件の対象を「陣営」ではなく「襲撃能力を持つ役職の集合」にする
- B: 役職に `counts_for_elimination: true/false` を持たせる
- C: `eliminate_role_tag: werewolf` のようにタグで指定する

## Q3 [Phase 1 前に必須] 初日・同数時などのゲームルール既定値

仕様に記載がない。すべて設定ファイル化する前提で既定値を決める。

- 初日処刑: あり / なし
- 初日占い: 自由占い / ランダム白 / 占いなし
- 初夜襲撃: あり / なし
- 投票同数: 決選投票 / ランダム / 処刑なし
- 連続護衛: 可 / 不可
- 狩人の自分護衛: 可 / 不可
- 霊能結果の通知タイミング: 当夜 / 翌朝
- 複数狼の襲撃先決定: 多数決 / 指定役 / ランダム

## Q4 [Phase 1 前に必須] 勝敗判定(GAME_END_CHECK)を走らせるタイミング

`parity`（狼数 >= 村人数）はいつ評価するかで結果が変わる。

候補: 処刑直後 / 襲撃解決直後 / 朝の開始時 / すべての死亡解決後

→ 「すべての死亡処理が解決した直後に必ず1回」が無難だが、明文化が必要。
