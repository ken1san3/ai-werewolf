# D056 Qwen優先と開発基盤への今週分の投資

## Status

Accepted — ユーザー方針（2026-09-07）。実装方式・詳細設計の承認ではない。

記録者: Codex / GPT-6 Astra。ユーザーの明示指示を記録し、Reviewer等の承認は代筆しない。

## Context

開発トークン削減案ではGeminiを日常的な調査・草稿担当に提案したが、ユーザーが優先順位を修正した。
ユーザーは「Qwenを基本使用」「geminiはGPT,claude,qwenの3つではできないかもったいないことを実行させる程度の消極的な使い方」と指示した。
また「今週1週間分のトークンを基盤開発に費やしてよい」と許可した。

## Decision

- 目指す開発基盤ではQwenを標準担当とする。通常の調査・草稿・契約に基づく実装・修正を含む。
- GPT/Claudeは重要設計、高リスク処理、独立レビュー、Qwenで収束しない問題を担当する。
- Geminiは通常経路に必須とせず、他の3モデルでできない、または任せると割に合わない具体的な理由がある場合のみ補助利用する。
- 今週分のトークンを、以後の反復消費を減らす開発基盤の整備へ投資してよい。使い切りは目的ではない。
- 数値のトークン上限、追加購入、定期実行、翌週以降の予算許可はこの発言から推定しない。

## Why

既存のQwen評価を活かし、モデル間の受渡しと上位モデルの反復作業を減らす。
短期の消費節約より、今週の基盤整備による日常開発の自動化を優先する。
