# D093: 保存証拠によるS4限定診断の許可

Status: ACCEPTED
Date: 2026-10-01

ユーザーはD092の次scopeについて「限定診断を実行せよ」と明示した。T551としてT550候補のS4 FAIL4行だけを保存証拠から追跡する。

許可はread-only診断、有限offline検算、記録、管理文書、常設commit/pushと終了監査に限る。source修正・新design・新測定の許可ではない。
既存意味判定の再採点・注釈変更、baseline/候補再生成、provider/model操作、game/Phase7、Actions/main変更、privacy/authority/validator緩和は禁止を維持する。

T550 WP0〜WP5は完了済みとして保持し、品質MEASUREMENT_INVALID/製品不採用を覆さない。T515/T549は一時停止。v1既定。
