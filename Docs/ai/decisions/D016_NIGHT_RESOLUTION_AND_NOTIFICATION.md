# D016 夜の解決順と、能力結果の通知範囲

## Status

Accepted (2026-08-29) — ユーザー決定
「呪殺した場合には占い結果(しみん)だけ伝え、夜死亡させます」
「Q20 の上二つはそのままで大丈夫です。内部死因はどちらでも大丈夫です」

## Decision

### 1. 解決順（priority）

| priority | 処理 | 備考 |
|---|---|---|
| 30 | Protect | 狩人の護衛 |
| 40 | Inspect | 占い。呪殺の死亡フラグもここで立てる |
| 50 | Attack | 襲撃。妖狐の耐性・護衛をここで評価 |
| 70 | DeathResolve | 死亡を確定させる |
| 75 | InspectDeadRole | 賢狼（D010）。死亡確定後 |
| 78 | Retaliation | 猫又の道連れ（D011） |
| 80 | FollowDeath | 後追い（Phase 8） |
| 90 | GameEndCheck | D005 / D014 |

値は設定可能にする（マスター仕様 §11）。上表は既定値。

### 2. 確定した相互作用

| 論点 | 決定 |
|---|---|
| 狩人の護衛は呪殺を防ぐか | **防がない**。護衛は人狼の襲撃のみを対象とする |
| 占い師が同じ夜に襲撃されても占いは成立するか | **成立する**。Inspect(40) が Attack(50) より先 |
| → その帰結 | **占い師が噛まれた夜でも呪殺は発生する** |
| 呪殺と襲撃が同一人物に重なった場合の内部死因 | `cursed`（priority が先のもの）。公開死因はどちらも `died_in_night` なので外部差は無い |
| 強欲な人狼の2人襲撃で片方だけ護衛された場合 | 対象ごとに独立に評価する |

「占い師が噛まれた夜でも呪殺が起きる」は人狼のセオリーに直結するため、
テストで固定すること。

### 3. 呪殺の扱い

```
Inspect(40)
  ├─ 占い師へ判定結果を返す  →  「人狼でない」のみ
  └─ 対象が妖狐なら死亡フラグを立てる（内部死因 cursed）

DeathResolve(70)
  └─ 妖狐が死亡する（その夜のうち）

公開死因 = died_in_night（D012）
```

**占い師に「呪殺した」とは伝えない。**
占い師が得るのは「人狼でない」という判定結果だけであり、
呪殺が起きたかどうかは翌朝の死亡者から推測するしかない。

これを破ると D012 で公開死因をマスクした意味が消える。
占い師が即座に「妖狐を殺した」と分かると、
妖狐の死が村側へ確定情報として流れるため。

### 4. 能力結果の通知範囲

| 状況 | 使用者は知るか | 通知先 |
|---|---|---|
| 狩人の護衛が襲撃を防いだ（GJ） | **知る** | 狩人のみ（private） |
| 狩人の護衛先が襲撃されなかった | **知らない** | — |
| 占い師が妖狐を占って呪殺した | **知らない**（判定結果のみ） | 占い師へ「人狼でない」 |
| 占いの判定結果 | 知る | 占い師のみ（private） |
| 霊能の判定結果 | 知る | 霊能者のみ（private） |
| 賢狼の役職情報 | 襲撃成功時のみ（D010） | 賢狼のみ（private） |
| 人狼の襲撃が防がれた | 専用通知は**出さない** | 朝の結果から推測 |
| 猫又の道連れで死んだこと | 公開（`died_in_day` / `died_in_night`） | 全員 |

「知らない」ケースは、**サーバが通知を送らない**ことで実現する。
クライアント側でフィルタしない（D001 / マスター仕様 §27）。

### 5. 襲撃失敗の見え方

以下はすべて村側から見て「夜に誰も死ななかった」で同一に見える。

- 狩人が護衛に成功した
- 妖狐を襲撃した
- （将来）襲撃が無効化された

賢狼も D010 により、いずれの場合も情報を得ない。区別が漏れない。

## Consequences

- 通知は Effect の副作用として発行し、宛先を Effect が持つ
- レビュー時の必須チェック: private 通知が
  ブロードキャスト経路に乗っていないか
- 情報漏洩テストとして「占い師のイベント列に呪殺を示す情報が無い」を追加

## Verification

- 妖狐を占うと、占い師は「人狼でない」だけを受け取り、その夜に妖狐が死亡する
- 占い師が受け取るイベントに呪殺を示す情報が一切含まれない
- 占い師が襲撃された夜でも、その夜の占いが成立し呪殺が発生する
- 狩人が妖狐を護衛しても呪殺を防げない
- 狩人が襲撃を防いだとき、狩人だけが GJ 通知を受け取る
- 狩人の護衛先が襲撃されなかったとき、狩人は何も受け取らない
- 護衛成功 / 妖狐襲撃 の2ケースで、村側の受信イベントが同一になる
