# D004 人狼ジャッジメントを参照実装とする

Status: Accepted (2026-08-29) / ユーザー決定

## Context

マスター仕様はゲームルールの既定値をほとんど定義していない。
実装者が個別に判断すると、後から全面的なやり直しになる。

## Decision

ルール・役職仕様・設定項目の判断基準を人狼ジャッジメント（そらいろ株式会社）に置く。
調査結果は `spec/JUDGMENT_REFERENCE.md` に集約し、再調査しない。
そこに無い場合は `OPEN_QUESTIONS.md` へ起票してユーザーへ確認する。

ただしそのままコピーはしない。逸脱する場合は Decision として明示的に記録する。

## Why

- ゲームバランスと細部が実プレイで検証済み
- 役職属性のデータモデルがそのまま設計の参考になる（D003）
- ユーザーがこのアプリのルールに習熟しており、仕様の疑問を短時間で解決できる

## Consequences

ルール設定が2層構造になる（D006）。
CO がシステム機能であることが判明した（D007）。
将来「人狼ジャッジメント互換モード」を content pack として持てる。

## Non-goals

UI・課金・ポイント・レーティングは対象外。100種類以上の役職を初期実装しない。
