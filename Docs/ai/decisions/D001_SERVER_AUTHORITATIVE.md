# D001 Server Authoritative

## Status

Accepted (2026-08-29) — マスター仕様 §1.1 / §1.2 より

## Context

AIプレイヤーと人間プレイヤーを同じクライアントとして扱いたい。
クライアント側にルール処理を持たせると、AIの誤判断がルールを変えてしまう。

## Decision

ゲーム状態・役職・生死・フェーズ・投票・能力可否・勝敗・秘匿範囲は
すべてサーバが決定・保持する。クライアントから来た操作は必ずサーバ側で検証する。

サーバはAIの推論ロジックを知らない。AIクライアントは正しいゲーム状態を保持しない。

## Why

- 人間参加・複数PC接続・別言語クライアントを後から足せる
- AI側のバグでルールが壊れない
- 秘匿情報をネットワーク段階で分離できる（プロンプトで隠す方式を禁止できる）

## Consequences

- サーバに検証コードが増える
- クライアントは「今できる操作」をサーバから受け取る必要がある（マスター仕様 §33）
- ゲームコアはLLMなしでテスト可能でなければならない
