# D001 Server Authoritative

Status: Accepted (2026-08-29) / 出典: マスター仕様 §1.1 §1.2

## Context

AIプレイヤーと人間プレイヤーを同じクライアントとして扱いたい。
クライアント側にルール処理を持たせると、AIの誤判断がルールを変えてしまう。

## Decision

ゲーム状態・役職・生死・フェーズ・投票・能力可否・勝敗・秘匿範囲は
すべてサーバが決定し、クライアントから来た操作はすべてサーバが検証する。

## Why

- 人間参加・複数PC接続・別言語クライアントを後から足せる
- AI側のバグでルールが壊れない
- 秘匿情報をネットワーク段階で分離でき、プロンプトで隠す方式を排除できる

## Consequences

サーバに検証コードが増える。クライアントは「今できる操作」を
サーバから受け取る必要がある（D017）。
