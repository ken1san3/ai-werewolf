出典: そらいろ株式会社 公式ヘルプ https://help.sorairo.jp/werewolf-judgment/
取得日: 2026-08-29 / 公式ヘルプ更新日: 2025-12-15

本プロジェクトのルール参照実装（`decisions/D004`）。
**再調査してトークンを使わないよう、必要な事実はここに集約する。**

---

## 1. 役職の属性モデル（最重要）

人狼ジャッジメントは、各役職を以下の**独立した軸**で定義している。
1つの「陣営」フィールドでは表現できない。

| 軸 | 取りうる値 |
|---|---|
| 陣営（勝利条件） | 市民陣営 / 人狼陣営 / 妖狐陣営 / その他 |
| 陣営カウント | 市民として数える / 人狼として数える / 数えない / 役職に準ずる |
| 襲撃結果 | 死亡 / 襲撃されない / 死なない / 役職に準ずる |
| 占い結果 | 人狼である / 人狼でない / 人狼でない（ただし呪殺される）/ 役職に準ずる |
| 霊能結果 | 人狼である / 人狼でない / 大狼 / 子狐 / 悪魔の眷属 / 役職に準ずる |

### 軸が独立している証拠

| 役職 | 陣営 | カウント | 襲撃 | 占い | 霊能 |
|---|---|---|---|---|---|
| 市民 | 市民 | 市民 | 死亡 | 人狼でない | 人狼でない |
| 占い師 | 市民 | 市民 | 死亡 | 人狼でない | 人狼でない |
| 霊能者 | 市民 | 市民 | 死亡 | 人狼でない | 人狼でない |
| 狩人 | 市民 | 市民 | 死亡 | 人狼でない | 人狼でない |
| 人狼 | 人狼 | 人狼 | 襲撃されない | 人狼である | 人狼である |
| **大狼** | 人狼 | 人狼 | 襲撃されない | **人狼でない** | **人狼である** |
| **狂人** | **人狼** | **市民** | 死亡 | 人狼でない | 人狼でない |
| 狂信者 | 人狼 | 市民 | 死亡 | 人狼でない | 人狼でない |
| ささやく狂人 | 人狼 | 市民 | 死亡 | 人狼でない | 人狼でない |
| **妖狐** | 妖狐 | **数えない** | **死なない** | 人狼でない（**呪殺**） | 人狼でない |
| **子狐** | 妖狐 | 数えない | 死亡 | 人狼でない | **子狐である** |
| 背徳者 | 妖狐 | 市民 | 死亡 | 人狼でない | 人狼でない |
| **狐憑き** | 妖狐 | **役職に準ずる** | 役職に準ずる | 役職に準ずる（呪殺） | 役職に準ずる |

- 大狼 → **占い結果と霊能結果は独立**
- 狂人 → **勝利陣営と陣営カウントは独立**
- 妖狐 → **陣営カウントに「数えない」がある**
- 狐憑き → **属性を元役職へ委譲する「役職に準ずる」がある**

## 2. 勝利条件

| 陣営 | 条件（公式ヘルプ原文ベース） |
|---|---|
| 市民陣営 | 全人狼死亡時 |
| 人狼陣営 | 「市民」の数を「人狼」の数以下にする |
| 妖狐陣営 | 市民陣営か人狼陣営が勝利した時に生存していると、その陣営に代わって勝利 |

- 市民勝利は「人狼**役職**の全滅」であり、人狼陣営（狂人を含む）の全滅ではない。
- 人狼勝利のカウントは**陣営カウント**を使う（狂人は市民として数えられる）。
- 妖狐は他陣営の勝利成立を「横取り」する形。単独で条件を持たない。

## 3. 基本役職の能力仕様

| 役職 | 仕様 |
|---|---|
| 占い師 | 毎夜一人を占い「人狼か否か」を判定。妖狐を占うと呪殺 |
| 霊能者 | 毎夜、**処刑・突然死した人**が「人狼/人狼でない/大狼/子狐/悪魔の眷属」か判定 |
| 狩人 | 毎夜一人を人狼襲撃から護衛。**自分は選べない**。九尾の狐・襲撃ゾンビからも防御可 |
| 人狼 | 毎夜指定した人物を襲撃。仲間の人狼を認識。秘密会話で連携 |
| 狂人 | 誰が人狼か**知らない**。秘密会話なし |
| 狂信者 | 誰が人狼か**知っている**（秘密会話は無し） |
| ささやく狂人 | 人狼と**秘密会話可能** |
| 妖狐 | 仲間の妖狐と秘密の会話ができる |

→ 「陣営」「知識（仲間を知るか）」「チャット権限」は**それぞれ独立**。
狂人 / 狂信者 / ささやく狂人はこの3軸の組み合わせ違いだけで区別される。

### 夜行動を選ばなかった場合（ユーザー確認済み）

**未選択時にサーバが強制選択するのは人狼の襲撃だけ。**
占い・護衛・霊能は未選択なら未選択のまま、その夜は能力が発動しない。

本プロジェクトの `no_selection`（D027）に落とすと、
`random` を宣言するのは襲撃能力のみ、他はすべて `skip` になる。

## 4. ルール設定項目（公式「ルールの設定」より）

**デフォルト値はヘルプに明記されていない。既定値はユーザー確認が必要。**

### 時間

| 設定 | 選択肢 |
|---|---|
| 屋敷の昼の長さ | 1分〜6分 |
| 屋敷の夜の長さ | 30秒〜120秒 |
| 話し合いの時計 | 砂時計 / 時計 |
| 15秒ルール | なし / あり（**夜明け直後の発言禁止**） |
| 時間延長回数 | なし〜5回（1回で2分延長） |
| 時短・延長成立人数 | 全員 / 過半数 |
| 時短・延長のプレイヤー名 | 見せない / 見せる |

### 投票

| 設定 | 選択肢 |
|---|---|
| 投票時の会話 | 話せない / 話せる |
| 投票先 | 見せない / 見せる / 終了後 |
| 決選投票 | なし / あり |
| 投票同数でランダム処刑 | 処刑しない / ランダム |
| 処刑見送り | なし / 1回 / 2回 |
| 投票未選択時 | 処刑見送り / 無効票 |
| 自身への投票 | できない / できる |
| 投票時間のスキップ | しない / する |

### CO（カミングアウト）— **システム機能である**

| 設定 | 選択肢 |
|---|---|
| 市民騙り | できない / できる |
| CO回数制限 | 1日3回 / 制限なし |
| 2日目のCO | できない / できる |

### 一般

| 設定 | 選択肢 |
|---|---|
| 役職欠け | ランダムに役職が市民に置き換わる |
| 役職希望 | なし / あり |
| 言葉づかい | 目上相手 / 一般 / 友達 / フリー |

### 観戦・墓場

| 設定 | 選択肢 |
|---|---|
| 観戦 | なし / 許可 |
| 観戦者の発言 | なし / 許可 |
| 観戦人数の表示 | なし / 許可 |
| 墓場の発言 | 見せない / 見せる |

### 役職固有ルール（抜粋）

| 設定 | 選択肢 | 対象 |
|---|---|---|
| 初日占い | なし / あり / **ランダム白** | 占い師系 |
| 連続ガード | なし / あり | 狩人系 |
| 双子の後追い | なし / あり | 双子 |
| 子狐の霊能結果 | 人狼でない / 子狐である | 子狐 |
| 魔女の薬 | 2回 / 1回 / 蘇生のみ | 魔女 |
| 人狼への変化数制限 | 無制限 / 1〜3人 | 変化系 |
| 逃亡しない | 生存 / 死亡 | 逃亡者 |
| 処刑代理選別 | 選択 / ランダム | 貴族の息子 |

→ 役職固有ルールが**数十項目**ある。
グローバル設定と役職ごとのオプションの**2層構造**が必須。

## 4.5 通常の役職に「重ねて付与される」もの

Role ではなく**オーバーレイ**として扱うべきもの（`decisions/D008`）。

| 名称 | 付与タイミング | 付与元 | 効果 |
|---|---|---|---|
| 狐憑き | 配役時 | 配役 | 勝利条件が妖狐陣営へ / 占われると呪殺 / 妖狐全滅で後追い |
| 恋人 | 初夜 | キューピット | 勝利条件が恋人陣営へ / 相方の死亡で後追い / 互いを認識 |
| 手玉 | ゲーム中 | 悪女 | 悪女の死亡で後追い |
| 呪い | 毎夜（一晩限り） | 背徳の呪術師 | その夜に占われると呪殺 |

- 狐憑きの全属性が「役職に準ずる」なのは、これが Role ではなくオーバーレイだから。
- 恋人は元の役職を保持したまま勝利条件だけが上書きされる。
  キューピット自身も恋人になれる。恋人同士は互いを認識する。
- 狐憑きになれない役職が存在する（人狼、怪盗、狂信者、ささやく狂人、
  キューピット、悪女、ゾンビ、妖狐陣営の役職）。

これとは別に、**役職そのものが差し替わる**機構もある
（光の使徒／闇の化身／銀色の影の変化、怪盗の交換）。両者を混同しないこと。

## 5. 本プロジェクトへの含意

1. 役職YAMLは `team` 1つでは足りない（`decisions/D003`）。
2. 勝利条件は「役職の全滅」と「陣営カウントの比較」の2種類が必要（`decisions/D005`）。
3. **CO は自由発言ではなくシステム操作**。回数制限・日数制限があるため、
   プロトコルに `co.declare` 相当のイベントが要る。マスター仕様に記述なし。
4. 投票は単純多数決ではない。決選投票・処刑見送り・無効票・自己投票の
   4つの設定が絡む。
5. 昼フェーズは固定時間ではなく、**時短・延長で伸縮する**。
6. チャットチャネルに `graveyard`（墓場）と `spectator`（観戦）が要る。
7. 役職固有オプションは役職定義側に持たせ、コアは知らない形にする。
8. 恋人・狐憑き等は Role ではなく Modifier（`decisions/D008`）。
   役職の差し替え（変化系）はさらに別機構。
